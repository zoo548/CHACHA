## 0. 한 줄 원칙

> "이 문자를 받은 사람에게 **옆에서 말로 알려준다**고 생각하고 쓴다."
> 정보를 많이 주는 것보다, **지금 무엇을 해야 하는지 이해시키는 것**이 목표다.

재난문자는 일반 쉬운정보보다 **시간이 없다**. 그래서 강의 원칙 중에서도 "두괄식", "한 문장 한 정보", "행동 중심"을 가장 강하게 적용한다.

## 1. 정보 범위 정하기 (무엇을 남기고 무엇을 뺄까)

강의의 정보 우선순위(가장 중요 → 필요 → 이미 아는 것 → 배경 → 불필요)를 재난문자에 적용한다.

| 우선순위 | 재난문자에서 | 처리 |
|---|---|---|
| ① 꼭 알아야 할 정보 | 무슨 일이 났는지, **지금 할 행동** | 반드시 남김, 맨 앞 |
| ② 필요한 정보 | 가면 안 되는 곳, 도움 요청 방법 | 남김 |
| ③ 이미 아는 정보 | "안전에 유의 바랍니다" 같은 상투어 | 삭제 |
| ④ 배경 정보 | 강수량(mm), 풍속(m/s), 기온 수치, 발효 시각 | 삭제 또는 쉬운 말로 바꿈 ("비가 아주 많이 와요") |
| ⑤ 불필요한 정보 | 발송기관명, 문의 번호 나열, 홍보 문구 | 삭제 (발송기관은 앱 화면 하단에만 작게 표시) |

**생략 금지 규칙**: 장소(어디), 시간(언제), 행동(무엇을)은 원문에 있으면 절대 빼지 않는다. (강의: "생략된 정보로 정확성이 떨어지지 않도록")

## 2. 메시지 구조 (모든 재난 공통 틀)

| 순서 | 이름 | 내용 | 규칙 |
|---|---|---|---|
| 1 | **제목** | 무슨 재난인지 | 재난 이름이 드러나게 (예: "센 태풍이 왔어요") |
| 2 | **상황 1문장** | 왜 위험한지 | 칸 이름 없이 제목 바로 아래. 제목과 겹치지 않게. **무엇 때문에 위험한지** 꼭 넣기 |
| 3 | **이렇게 해요** | 행동 기본 4개 (최대 6개) | 번호 목록. 가장 중요한 것 먼저. 중요한 내용을 빠뜨리지 않기 위해 1~2개 추가 가능 |
| 4 | [ 알았어요 ] 버튼 | | 누르면 기기에 `C` 전송 |

### 🔴 H 행동 순서 (고정)

1. **몸을 지키는 행동 1개** (재난별)
2. 지금 바로 {보호자}에게 전화해요.
3. 전화를 안 받으면 {이웃}에게 전화해요.
4. 아무도 안 받으면 119에 전화해요.
5. (필요하면) 가면 안 되는 곳 등 중요한 행동 1~2개 추가

- **"○○로 대피해요"처럼 장소를 지시하지 않는다.** 혼자 판단해서 이동하게 하지 않고, 도와줄 사람과 연결하는 것을 우선한다.

### 🟡 L 행동

- 집 안에 있기, 가면 안 되는 곳, 재난별 준비 행동 + 마지막에 {보호자} 또는 119 연락.

### 이름 넣는 자리 (슬롯)

| 슬롯 | 뜻 | 없을 때 |
|---|---|---|
| `{보호자}` | 앱에 등록한 1순위 연락처 (예: 엄마) | "보호자"로 표시 |
| `{이웃}` | 앱에 등록한 2순위, 가까이 사는 사람 | **그 줄을 숨김** |

- 근거: 장애인개발원 가이드의 대비카드(지원자 1·2순위), "30분 안에 와줄 수 있는 지원자 1명 이상 지정"(9쪽)
- 앱 구현 시 조사 처리 필요: 엄마**나**/선생님**이나**, 엄마**와**/선생님**과**

## 3. 문장 쓰기 규칙

| # | 규칙 | 기준 | 예시 |
|---|---|---|---|
| S1 | 한 문장에 정보 1개, 동사 1개 | 쉼표로 절 잇지 않기 | ✗ 창문을 닫고 집 안에 있어요 → ✓ 창문을 닫아요. / 집 안에 있어요. |
| S2 | 짧게 | **공백 포함 25자 이내** (권장 20자) | |
| S3 | 해요체 구어체 | "~해요", "~예요" | ✗ 외출을 자제 바랍니다 → ✓ 집 안에 있어요 |
| S4 | 서술형 완성 문장 | 개조식(~함, ~바람) 금지 | ✗ 입산 금지 → ✓ 산에 가지 마세요 |
| S5 | 긍정문 우선 | 금지가 꼭 필요하면 `avoid`에서 **긍정문을 짝으로** | 가지 마세요 → "대신 집 안에 있어요" |
| S6 | 이중부정 금지 | | ✗ 나가지 않으면 안 돼요 |
| S7 | 비유·관용어 금지 | 직설적·사실적으로 | ✗ 물폭탄 → ✓ 비가 아주 많이 와요 |
| S8 | 주어는 구체적으로 | 필요할 때 "나", "보호자", "안내하는 사람" | |
| S9 | 대명사·모호한 말 금지 | "그곳", "옆 사람", "그래도 안 되면" 대신 구체적으로 | ✗ 그래도 안 되면 → ✓ 아무도 안 받으면 |
| S10 | 한자어 칸 이름 금지 | "상황" 같은 칸 이름을 쓰지 않음 | |

## 4. 어휘 규칙

| # | 규칙 | 적용 |
|---|---|---|
| W1 | 한자어·전문용어 → 일상어 | 아래 **변환 사전** 사용 |
| W2 | 꼭 알아야 할 어려운 말은 그대로 쓰고 설명 | `대피`, `대피소`, `태풍`, `119` → 앱에서 단어를 누르면 설명(`glossary`) |
| W3 | 같은 뜻 = 같은 단어 (동의어 섞지 않기) | "대피해요"로 통일 (피난/대피/이동 혼용 금지) |
| W4 | 숫자는 아라비아 숫자 | 12시간제: "오후 3시" (15시 ✗) |
| W5 | %, mm, ℃, m/s, 기호(&, /, ~) 금지 | "비가 아주 많이 와요", "아주 더워요" |
| W6 | 줄임말 금지 | 지하차도 ✗ → "땅 밑으로 가는 길" (※ 감수 때 확인 필요) |

### 변환 사전 (1차)

| 원문 표현 | 쉬운 표현 |
|---|---|
| 호우 / 집중호우 / 극한호우 | 비가 많이 와요 / 비가 아주 많이 와요 |
| 침수 | 물이 차요 / 물이 넘쳐요 |
| 하천변, 계곡, 저지대 | 강, 개울, 계곡 / 낮은 곳 |
| 지하차도, 지하주차장 | 지하 주차장, 땅 밑으로 가는 길 |
| 외출 자제 | 집 안에 있어요 |
| 야외활동 자제 | 밖에 오래 있지 않아요 → 집 안에 있어요 |
| 수분 섭취 | 물을 자주 마셔요 |
| 온열질환 | 더워서 몸이 아픈 것 |
| 강풍 | 아주 센 바람 |
| 입산 금지 / 입산 자제 | 산에 가지 마세요 |
| 인근 주민 | 가까이 사는 사람 |
| 주변 사람 | 큰 소리로 "도와주세요" 하고 말해요 (대상 없이) |
| 유독가스, 연기 다량 발생 | 연기가 많이 나요 |
| 즉시 대피 | 지금 바로 대피해요 |
| 대피소 / 대피장소 | 대피소 (단어 설명 제공) |
| 안전에 유의 바랍니다 | (삭제) |

## 5. 보조 이미지(아이콘) 규칙

강의 핵심: **"쉬운 글이 먼저, 이미지는 거든다."** 이미지가 많다고 쉬워지지 않는다.

- 메시지 1개에 **대표 그림 1개**(`hero_icon`) + 행동 문장마다 **최대 1개**(`icon`).
- 핵심 행동 1~2개에만 그림을 쓴다. 모든 문장에 넣지 않는다.
- 성인용 → **아기 캐릭터·유아 그림체 금지**. 단순한 선 그림(픽토그램).
- 과한 장식·깜빡이는 애니메이션 금지 (감각 과민 고려, 기기 LED와도 경쟁하지 않게).
- 등장인물은 한 명으로 통일 (모든 재난에서 같은 사람).
- 그림과 글은 **좌-우로 한 줄에 묶어서** 배치 (시선 이동 최소화).

## 6. 화면 디자인 규칙 (앱)

강의의 프린트미디어 기준을 앱 화면에 옮긴 값. 3차 회의에서 앱 피드백 때 확정.

- 고딕(산세리프) 1종, 본문 **20pt 이상** (앱 기준 상향), 줄간격 1.8배
- 왼쪽 정렬, 의미 단위로 줄바꿈 (단어가 줄 끝에서 끊기지 않게)
- 한 문장 = 한 줄
- 위험 등급 색은 기기와 통일: H = 빨강, L = 노랑 (제목 배경색)
- 화면 맨 아래 큰 버튼 1개: **"알았어요"** → 누르면 기기에 `C` 전송

## 7. 위험 등급 → 기기 신호 매핑

| 앱 등급 | 언제 | 기기 | 템플릿 `level` |
|---|---|---|---|
| **H** | 대피가 필요한 문자 (대피 명령, 긴급재난문자 중 "즉시 대피") | 빨간불 점멸 + 진동 반복 | `evacuate` |
| **L** | 주의가 필요한 문자 (주의보·경보 안내, 외출 자제 등) | 노란불 + 진동 1회 | `caution` |

- 폭염은 1차 버전에서 **L만** 둔다 (대피 명령이 거의 없음).
- 화재도 **L만** 둔다. 건물 안 화재는 범위에서 제외 — 재난문자는 "인근 주민 창문 닫기·우회" 같은 근처 안내로만 오고, 불난 건물 안 사람에게는 거의 오지 않기 때문 (화재경보·안내방송으로 인지).
- 원문에 "대피"가 들어 있으면 재난 종류와 상관없이 H로 올린다 (`matching.escalate_keywords`).

## 8. 절차: 만들기 → 확인 → 감수

1. **초안 작성** (혜성·다은) — 이 가이드의 체크리스트 통과
2. **자동 검사** — `validate_templates.py` (문장 길이, 금지 기호, 24시간제, 이중부정 등)
3. **소리 내어 읽기** — 둘이 번갈아 읽으며 막히는 곳 표시 (강의 감수회 방식)
4. **당사자 감수** (10/16~10/20) — 감수위원 3~5명, 성별·장애유형 고르게
   - 질문은 열린 질문 + 객관식 병행 ("이 문자를 받으면 뭘 할 거예요?")
   - **선호 의견과 이해 의견을 구분**해서 기록
5. **전문가 검토** — 행동요령이 공식 국민행동요령과 어긋나지 않는지 (정확성)

## 10. 남은 결정 (v0.2 기준)

1. **산불 🔴 1번**: "안내하는 사람이 오면 따라가요"(기다리는 행동) vs "젖은 수건으로 코와 입을 막아요"(바로 하는 행동)
2. **폭염 "낮" 시간**: 장애인개발원 가이드 오후 12시~4시 vs 기존 안 12시~5시 → 공식 국민행동요령 확인
3. **실제 재난문자 원문 수집**: 템플릿의 원문 예시는 재구성한 것 → 휴대폰 긴급알림 기록 / 국민재난안전포털 / 재난안전데이터공유플랫폼 API
4. **앱 기능 후보**: 구조대원에게 보여줄 "내 카드"(장애인개발원 대비카드), H 알림 시 가까운 대피소 표시
5. **폭염 H 등급**, **앱 글자 크기 20pt** — 감수·시연 때 확인
