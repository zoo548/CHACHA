# 그림이 필요한 행동

`disaster_templates.json` 에서 `icon` 필드가 없는 행동입니다. 비슷한 행동은 같은 그림 이름으로 묶었습니다.
이미 있는 그림 이름(`stay_home`, `phone_119` 등)은 그대로 쓰고, 없는 이름만 새로 그리면 됩니다.

## anti_slip

- 미끄럽지 않은 신발을 신어요.
