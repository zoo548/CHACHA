# 차차등 통신 프로토콜

앱과 차차등은 BLE Nordic UART Service로 한 글자 + 줄바꿈(`\n`)만 주고받는다.
색·점 개수·쉬운 등급 이름은 앱 화면과 차차등이 같게 맞춘다.

## 1. 명령표 (앱 → 차차등)

| 명령 | 언제 | 점 | 색 |
|---|---|---|---|
| `I\n` | 안전안내문자 | ● | 파랑 `#1B64DA` |
| `L\n` | 긴급재난문자 | ●● | 주황 `#E8710A` |
| `H\n` | 위급재난문자 | ●●● | 빨강 `#D92D20` |
| `R\n` | 위급이면서 호우(`heavy_rain`) | ●●● | 빨강 `#D92D20` |
| `C\n` | 확인. 불·소리·진동을 끈다 | — | 끔 |
| `F\n` | 차차등 목소리를 여성으로 | — | — |
| `M\n` | 차차등 목소리를 남성으로 | — | — |

예전 안전안내 명령 `B`는 쓰지 않는다. `I`로 보낸다.

우선순위: **H / R > L > I**. 높은 알림이 켜져 있을 때 낮은 알림이 오면 무시한다. `C`는 언제나 끈다. `F`/`M`은 알림 우선순위에 넣지 않는다.

## 2. 점 · 소리 · 진동

차차등 점 개수와 앱 제목 띠의 점은 같다.

| 명령 | 점 | LED | 소리 | 진동 |
|---|---|---|---|---|
| `I` | ● | 파란불 켜짐 (확인할 때까지) | 안내 음성 1회 | 짧게 1회 |
| `L` | ●● | 주황불 켜짐 (확인할 때까지) | 주의 음성 | 중간 세기 |
| `H` | ●●● | 빨간불 반복 | 위급 음성 | 확인할 때까지 반복 |
| `R` | ●●● | 빨간불 반복 (호우) | 호우 음성 | 확인할 때까지 반복 |
| `C` | 끔 | 모두 끔 | 끔 | 끔 |

목소리는 설정에서 고른 `F`/`M`을 따른다. 고르면 바로 보내고, 차차등이 다시 연결돼도 저장된 값을 다시 보낸다.

## 3. 확인 흐름

앱 화면의 확인 버튼 글자는 **"알았어요"** 로 통일한다.

1. **앱에서 알았어요를 누르면**  
   차차등에 `C\n`을 보낸다. 알림을 닫고 홈으로 간다.

2. **차차등 버튼을 눌러 확인 신호가 오면**  
   먼저 앱 알림을 확인 처리하고 홈으로 간다.  
   그다음 차차등에 `C\n`을 보내 불까지 끈다.

기기 → 앱 확인 신호는 지금도 `C`(버튼)이다.

## 4. 앱 화면에 쓰는 이름

| 명령 | 쉬운 이름 (크게) | 정부 이름 (작게) |
|---|---|---|
| `I` | 알아두세요 | 안전안내문자 |
| `L` | 조심해요 | 긴급재난문자 |
| `H` / `R` | 지금 해야 해요 | 위급재난문자 |
