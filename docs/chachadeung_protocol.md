# 차차등 통신 프로토콜

앱과 차차등은 BLE Nordic UART Service로 한 글자 + 줄바꿈(`\n`)만 주고받는다.
색·점 개수·쉬운 등급 이름은 앱 화면과 차차등이 같게 맞춘다. 등급은 정부 발송 유형이 아니라 차차 기준(`src/alerts/tier.ts`)이다.

## 1. 명령표 (앱 → 차차등)

| 명령 | 언제 | 점 | 색 |
|---|---|---|---|
| `I\n` | 알아두세요. 나머지 `caution` | ● | 파랑 `#1B64DA` |
| `L\n` | 조심해요. 지정 `caution` | ●● | 주황 `#E8710A` |
| `H\n` | 지금 해야 해요. `evacuate` | ●●● | 빨강 `#D92D20` |
| `R\n` | `evacuate` 이면서 호우(`heavy_rain`) | ●●● | 빨강 `#D92D20` |
| `C\n` | 확인. 불·소리·진동을 끈다 | — | 끔 |
| `F\n` | 차차등 목소리를 여성으로 | — | — |
| `M\n` | 차차등 목소리를 남성으로 | — | — |
| `Q\n` | 소리 끄기. 소리에 예민해요 | — | — |
| `N\n` | 소리 보통 | — | — |

예전 안전안내 명령 `B`는 쓰지 않는다. `I`로 보낸다.

우선순위: **H / R > L > I**. 높은 알림이 켜져 있을 때 낮은 알림이 오면 무시한다. `C`는 언제나 끈다. `F`/`M`/`Q`/`N`은 알림 우선순위에 넣지 않는다. 차차등이 기억한다.

## 2. 점 · 소리 · 진동

차차등 점 개수와 앱 제목 띠의 점은 같다.

| 명령 | 점 | 설명 |
|---|---|---|
| `I` | ● | 파랑 점 1개, 띵 한 번 |
| `L` | ●● | 주황 점 2개, 1초에 1번 깜빡, 차임·진동 30초 |
| `H` | ●●● | 빨강 점 3개, 빠르게 깜빡, 차임·음성·진동 반복 |
| `R` | ●●● | H와 같음, 폭우 음성 |
| `C` | 끔 | 모두 끔 |

목소리는 설정에서 고른 `F`/`M`을 따른다. 소리는 설정에서 고른 `Q`(끄기) / `N`(보통)을 따른다. 고르면 바로 보내고, 차차등이 다시 연결돼도 저장된 값을 다시 보낸다. `F`/`M`과 `Q`/`N`은 연결될 때마다 같이 한 번 보낸다.

## 3. 확인 흐름

앱 화면의 확인 버튼 글자는 **"알았어요"** 로 통일한다.

1. **앱에서 알았어요를 누르면**  
   차차등에 `C\n`을 보낸다. 알림을 닫고 홈으로 간다.

2. **차차등 버튼을 눌러 확인 신호가 오면**  
   먼저 앱 알림을 확인 처리하고 홈으로 간다.  
   그다음 차차등에 `C\n`을 보내 불까지 끈다.

기기 → 앱 확인 신호는 지금도 `C`(버튼)이다.

## 4. 앱 화면에 쓰는 이름

제목 띠는 차차 쉬운 이름만 크게 쓴다. 정부 문자 이름은 화면 맨 아래 작은 회색 글씨로, 발송 기관과 같이 둔다.

| 명령 | 쉬운 이름 (제목 띠, 크게) |
|---|---|
| `I` | 알아두세요 |
| `L` | 조심해요 |
| `H` / `R` | 지금 해야 해요 |

## 5. 기기 버튼

| 조작 | 하는 일 |
|---|---|
| 한 번 누름 | 알림 확인. 기기→앱 `C` |
| 두 번 누름 | 시연용 단계 순환 |
| 3초 누름 | 연결 확인 |
